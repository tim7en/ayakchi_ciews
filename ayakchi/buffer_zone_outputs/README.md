# Ayakchi 5 km buffer-zone screening

Land-cover, built-surface and indicative population screening for the connected basin, its 5 km context buffer, and a 2 km corridor around the dam-to-outlet flow path. The buffer and corridor support CIEWS stakeholder and exposure discussions; neither is a flood-inundation or dam-break boundary.

`landcover_statistics.csv` and `exposure_statistics.csv` summarize the nested analysis zones. Satellite classifications and global population estimates require local validation.
