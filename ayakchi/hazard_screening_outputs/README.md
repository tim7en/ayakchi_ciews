# Ayakchi hazard screening maps

Seven relative susceptibility products derived from the existing morphology, hydrology and Earth Engine layers. Each hazard has a continuous 0–1 index, a five-class raster and a 300 dpi map. See `methodology.json` for weights and limitations and `hazard_class_areas.csv` for class areas.

These are prioritization layers for CIEWS development, not calibrated hazard probabilities, forecasts, flood depths or engineering-design products. Validation requires event inventories and local soils, geology, infrastructure and exposure data.
